# Tauhid Portfolio Design Clone

A clean Next.js + TypeScript + Tailwind reconstruction of the visual architecture of the referenced single-page portfolio.

## Run

```bash
npm install
npm run dev
```

## Notes

- The implementation recreates the design system, layout, responsive grids, navigation, cards, filters, testimonial controls, contact form styling, and floating CTA.
- Public-facing copy and portrait imagery are intentionally represented with placeholders. Replace them with content/assets you own.
- The source website was inspected live on 2026-08-26.
